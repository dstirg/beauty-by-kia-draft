# Beauty by Kia — Draft Review

This repository contains a review-only prototype of the Beauty by Kia booking portal.

## Draft safeguards

- Pricing, deposits, availability, and policies are placeholders awaiting Kia's approval.
- Payment buttons are demonstrations only.
- The site does not collect card details or process real payments.
- The public banner and page title identify the site as a draft.

The site is a static, browser-based preview intended for design and booking-flow feedback.
